## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Adicionar feedback visual (toast) após ações bem-sucedidas em BuildsListManager e CompBuildsManager. Atualmente silenciosas.

## Ações que precisam de toast
- duplicar build → 'Build duplicada'
- tornar pública/privada → 'Visibilidade alterada'
- excluir build → 'Build excluída'
- adicionar build à comp → 'Build adicionada'
- remover build da comp → 'Build removida'
- salvar build (EditorActionBar) → 'Build salva'

## Approach sugerido
Instalar sonner (leve, sem deps) e adicionar <Toaster /> no layout.tsx. Chamar toast.success() após cada ação bem-sucedida nos try/catch existentes.

## Arquivos
- src/components/builds/BuildsListManager.tsx
- src/components/comp/CompBuildsManager.tsx
- src/components/editor/EditorActionBar.tsx
- src/app/layout.tsx (adicionar <Toaster />)
